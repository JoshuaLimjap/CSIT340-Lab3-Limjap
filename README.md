# CSIT340G8-Lab2-Limjap

A personal portfolio website built using React, Vite, and Tailwind CSS.

## Technologies Used
- React
- Vite
- Tailwind CSS
- JavaScript

## Getting Started

To run the project locally:

1. Install dependencies:
   `npm install`

2. Start the development server:
   `npm run dev`

3. Open the local URL provided in the terminal.
